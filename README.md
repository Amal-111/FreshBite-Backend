# FreshBite – Backend

FreshBite is a dynamic web application for managing and sharing healthy recipes, developed as part of the Advanced Web Applications course at King Saud University.

This repository contains the backend implementation of the FreshBite project, including server-side functionality, database interactions, user authentication, recipe management, and AJAX-based operations.

## Key Features

- User registration, login, and logout
- User session and role management
- Recipe creation, editing, viewing, and deletion
- Database integration using MySQL
- Likes, favourites, comments, and reports
- Admin functionality for managing reported content
- AJAX-based operations for selected features without full page reloads

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- jQuery
- AJAX
