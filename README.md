# FreshBite – Backend

FreshBite is a web application developed as part of the Advanced Web Applications course at King Saud University.

The platform is designed to help users discover, share, and manage healthy recipes through an interactive recipe platform. Recipes are organized into different categories, including seafood, meat, and vegan dishes.

This repository contains the backend implementation of the FreshBite project, providing the server-side functionality and database operations required for the dynamic features of the platform.

## Project Overview

FreshBite allows users to create accounts, explore recipes, manage their own recipes, and interact with recipe content.

The backend handles user authentication, sessions, recipe management, database operations, and other dynamic interactions between users and the platform.

## Key Features

- User registration, login, and logout
- User authentication and session management
- Recipe creation, editing, and deletion
- View and manage personal recipes
- Store and retrieve recipe data using MySQL
- Like and favorite recipes
- Add comments to recipes
- Report recipe content
- Administrative management of reported content
- Dynamic operations using AJAX
